بيانات الموظف

أدخل البيانات المطلوبة؛ تتم المعالجة محلياً داخل المتصفح.

ما تم تغييره لرفع التوافق
  • PNG ثابت بدلاً من SVG داخل التوقيع.
  • جداول HTML فقط مع Inline Styles.
  • بدون Flex/Grid أو صور خلفية أو تدرجات داخل التوقيع.
  • Tahoma / Arial / Segoe UI فقط.
  • روابط مباشرة + نسخة نصية Plain Text كبديل.

المعاينة

المعاينة تقريبية؛ العرض النهائي قد يختلف بدرجة بسيطة بين برامج البريد.

Outlook Classic / New Outlook

انسخ التوقيع من الصفحة والصقه في إعدادات التوقيع. إذا غيّر Outlook المسافات، لا تعِد تنسيقه يدوياً.

Gmail / Google Workspace

الإعدادات ← عام ← التوقيع، ثم الصق التوقيع المنسق واحفظ التغييرات.

Apple Mail / الهاتف

يفضل إعداد التوقيع من الكمبيوتر أولاً. النسخة النصية متاحة كحل احتياطي عند منع HTML أو الصور.
