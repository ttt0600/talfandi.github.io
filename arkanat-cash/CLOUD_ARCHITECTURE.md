# معمارية النسخة المشتركة المستقلة

## الهدف
تحويل بوابة العهد النقدية من تخزين LocalStorage على جهاز واحد إلى قاعدة بيانات مشتركة مستقلة، دون أي اتصال بـ Guard Control أو أنظمة الموظفين أو الرواتب أو العمليات.

## المكونات
- GitHub Pages: الواجهة فقط.
- Supabase مستقل: قاعدة البيانات والمصادقة.
- ملفات Excel: يتم تحليلها داخل المتصفح أولاً ثم ترحيل السجلات المعتمدة إلى القاعدة.
- لا ترفع ملفات Excel الأصلية إلى المستودع العام.

## الجداول
1. cash_requests
2. cash_transactions
3. cash_imports
4. cash_audit_log

## الضوابط
- الطلب لا ينشئ حركة نقدية حتى تسجيل التنفيذ.
- التمويل الجزئي مسموح.
- التحويل بين عهدتين ينشئ طرفي الحركة.
- Snapshot يحيد اللقطة السابقة لنفس النطاق.
- Delta يضيف الجديد فقط.
- العهدة الفرعية المفتوحة ليست مصروفاً.
- مرشح الخصم لا يعني خصماً فعلياً.
- الأصل المصدر والتاريخ الخام محفوظان.
- كل عملية مهمة لها Audit Trail.

## الوصول
النسخة الأولى المشتركة ستقصر الوصول على مستخدمين مصادق عليهم. لا توجد صلاحية anonymous على بيانات العهد.

## الترحيل من النسخة المحلية
عند تفعيل المشروع المشترك:
1. المستخدم يسجل الدخول.
2. البوابة تقرأ بيانات LocalStorage.
3. تعرض عدد الطلبات والحركات والمصادر.
4. يختار المستخدم «ترحيل بيانات هذا الجهاز».
5. يتم منع التكرار بمفاتيح المصدر/البصمة/معرفات السجلات.
6. تحفظ نسخة JSON احتياطية قبل الترحيل.
7. بعد المطابقة يمكن اختيار الوضع المشترك كالوضع الافتراضي.
