# بوابة العهد النقدية — أركانات

نسخة MVP مستقلة تعمل من المتصفح ولا ترتبط حالياً بـ Guard Control أو أي نظام مؤسسي آخر.

## الخصوصية
المستودع وصفحة GitHub Pages يحتويان على كود التطبيق فقط، ولا يتم تضمين بيانات العهد التشغيلية أو بيانات الموظفين في المستودع العام. ملفات Excel التي يختارها المستخدم تتم معالجتها داخل المتصفح، والبيانات الناتجة تحفظ في LocalStorage على الجهاز نفسه.

## الوظائف الحالية
- لوحة تحكم نقدية.
- سجل الحركات.
- طلبات العهد.
- تغذية العهد.
- التغطيات والمصروفات النقدية.
- التحويل بين العهد.
- مراجعة المالية.
- التصفية.
- اكتشاف الاستثناءات.
- استيراد Excel.
- تصدير Excel.
- نسخ احتياطي JSON.

## ملاحظة
هذه نسخة تجريبية أولية وليست نظاماً محاسبياً نهائياً، والغرض منها تثبيت دورة العمل وتجربة الاستخدام قبل إنشاء قاعدة بيانات مشتركة متعددة المستخدمين.
