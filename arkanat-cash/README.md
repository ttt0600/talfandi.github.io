# بوابة العهد النقدية — أركانات

نسخة MVP مستقلة تعمل من المتصفح ولا ترتبط حالياً بـ Guard Control أو أي نظام مؤسسي آخر.

## الإصدار الحالي
v0.7 — محرك استيراد متعدد الأنماط + مطابقة المصدر + دعم العهد الفرعية + التصفية الشهرية حسب الموقع + نتائج UAT تاريخية.

## الخصوصية
المستودع وصفحة GitHub Pages يحتويان على كود التطبيق فقط، ولا يتم تضمين بيانات العهد التشغيلية أو بيانات الموظفين في المستودع العام. ملفات Excel التي يختارها المستخدم تتم معالجتها داخل المتصفح، والبيانات الناتجة تحفظ في LocalStorage على الجهاز نفسه.

## ما يدعمه محرك الاستيراد
- كشوف التغطيات المباشرة مثل ملفات الشرقية.
- دفاتر الأستاذ متعددة المشرفين بنمط مدين / دائن / رصيد.
- دفاتر الوقود والمصروفات بنمط منصرف من العهدة / وارد للعهدة / رصيد العهدة.
- ملفات طلبات العهد التي تحتوي المبلغ والمشرف وIBAN واسم الحساب.
- ملفات متعددة الشيتات؛ يتم تحليل كل شيت بصورة مستقلة.
- الاحتفاظ بالتاريخ كما ورد في المصدر إلى جانب التاريخ المفسر.
- الاحتفاظ برقم الحركة التاريخي والشيت والصف واسم الملف.
- وضع Snapshot للملفات التي تمثل نسخة كاملة محدثة، لمنع جمع اللقطة الجديدة مع القديمة.
- وضع Delta للملفات التي تحتوي حركات إضافية فقط، مع تجاوز المكرر.
- إيقاف أي شيت غير معروف بدلاً من استيراده بتفسير خاطئ.\n- تعيين يدوي لصف العناوين ونوع الملف والأعمدة عند ظهور صيغة Excel مستقبلية غير معروفة، بدون تعديل الملف الأصلي.

## الوظائف الحالية
- لوحة تحكم نقدية.
- سجل الحركات.
- طلبات العهد.
- الرصيد الافتتاحي والتغذيات المتكررة.
- التغطيات والمصروفات النقدية.
- التحويل بين العهد.
- مراجعة المالية.
- التصفية.
- ملخص المصروفات حسب الموقع لنهاية الشهر.
- مرشحات الاسترداد/الخصم كمخرجات مراجعة فقط بدون خصم تلقائي.
- اكتشاف الاستثناءات.
- سجل ملفات الاستيراد.
- استيراد Excel.
- تصدير Excel.
- نسخ احتياطي JSON.

## فلسفة البيانات
- فصل حامل العهدة عن المشرف التشغيلي عند اختلافهما.
- العهد الفرعية المفتوحة تبقى نقداً بعهدة الشركة وليست مصروفاً.
العملية النقدية هي الوحدة الأساسية، وليس ملف الشهر. ملف Excel يعد مصدراً أو Snapshot يمكن استيراده، بينما تحتفظ البوابة بتاريخ المصدر والحركة وحالتها لتجنب ازدواج الاحتساب.

## المرحلة الحالية
النسخة تجريبية وتخزن البيانات محلياً. الهدف الحالي تثبيت دورة العمل واختبار الاستيراد والتصدير قبل الانتقال إلى قاعدة بيانات مشتركة متعددة المستخدمين.
